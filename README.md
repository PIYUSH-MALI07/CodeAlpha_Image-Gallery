## 🌟 Key Features

- **UHD Photographs:** 7 curated categories (Nature, Architecture, Animals, Travel, Cars, Bikes, Anime) with high-definition images in each section.
- **Bespoke Charcoal UI:** Modern developer aesthetic using Inter typography and dense masonry grid alignment.
- **Real-Time Instant Search:** Real-time search input field to filter photos by title or keyword.
- **2-Step Click Fullscreen Mode:**
  - *Step 1:* Click any image card to open Lightbox Modal View.
  - *Step 2:* Click image inside Lightbox to enter Fullscreen mode.
- **Direct HD Download:** One-click instant HD image download.
- **Light & Dark Theme Switcher:** Theme toggle with `localStorage` memory.
- **Keyboard Navigation:** Arrow keys for next/prev images and `Escape` key to close.
