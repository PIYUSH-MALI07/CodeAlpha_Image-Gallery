# 📸 Interactive Image Gallery — CodeAlfa Task 1

A responsive, feature-packed **Image Gallery** built as Task 1 for the **CodeAlfa Frontend Development Internship**.

Developed by **Piyush Mali**.

It showcases **160+ high-definition photographs** across **7 curated categories** (Nature, Architecture, Animals, Travel, Cars, Bikes, Anime) with a bespoke charcoal UI, real-time search, live category filtering, 2-step fullscreen mode, instant **HD & UHD** downloads, and a scroll-in **Back-to-Top** button.

## ✨ Key Features

- 🖼️ **UHD Photographs** — 7 curated categories: Nature, Architecture, Animals, Travel, Cars, Bikes & Anime.
- 🔎 **Real-Time Instant Search** — live filtering of photos by title or category keyword as you type.
- 🗂️ **Category Filter Tabs** — segmented tab bar with instant switching and per-category photo counts.
- 🌗 **Light / Dark Theme Switcher** — one-click theme toggle with `localStorage` memory.
- 📥 **HD & UHD Downloads** — two one-click buttons in the lightbox: **HD (1920px)** and **UHD / 4K (3840px)** downloads, saved with proper filenames.
- 🖱️ **2-Step Fullscreen Mode** — *Step 1:* click a card to open the Lightbox; *Step 2:* click the photo for native Fullscreen.
- ⬆️ **Back-to-Top Button** — floats in on scroll and smooth-scrolls you back to the top.
- ⌨️ **Keyboard Navigation** — `←` / `→` arrow keys switch between images, `Esc` exits the lightbox or fullscreen.
- ✨ **Bespoke UI Details** — staggered card cascade animations, neon glow accents, ripple click effects, and a glossy card shine on hover.
- 🔑 **Login / Sign In Demo** — front-end auth flow with client-side validation and success toasts (stored in `localStorage`).

## 🎯 How to Use

1. **Download / clone** the folder or copy the files.
2. **Open** `index.html` directly in any modern browser — no build step or server required.
3. **Browse** — use the category tabs, the search bar, or just scroll the masonry grid.
4. **View** — click any card to open the lightbox; click the photo again for fullscreen; navigate with `←` / `→` and close with `Esc`.
5. **Download** — press **Download HD** or **Download UHD** to save the current photo at high resolution.
6. **Theme** — toggle 🌙/☀️ in the navbar (your choice is remembered).
7. **Account** — try the demo **Login / Sign In** flow with instant validation feedback.
